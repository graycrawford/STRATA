# STRATA
STRATA is a musical VR experience, the result of my early explorations into spatial interfaces, mapping cloth physics / dynamics to musical phenomena.

All music composed by myself, OPTIA [ www.soundcloud.com/optia ]


Requires Leap Motion


Poke the cube to begin, and explore! And listen!


## Native Apple Vision Pro port

`STRATA-visionOS/` contains a native SwiftUI + RealityKit recreation
(ARKit hand tracking, a position-based cloth simulation, and an AVAudioEngine
mix that reproduces the original displacement → sound mappings). See
[`STRATA-visionOS/README.md`](STRATA-visionOS/README.md) for build steps.
